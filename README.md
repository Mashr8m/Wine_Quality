## 1. Описание проекта

Проект предназначен для предсказания качества вина на основе его физико-химических характеристик с использованием методов машинного обучения.

Для решения задачи используется модель бинарной классификации — Logistic Regression.

Модель определяет:
- `1` — хорошее вино (оценка качества 7 и выше);
- `0` — вино с оценкой качества ниже 7.

## 3. Установка зависимостей

Для работы проекта необходим Python 3.11 или выше.

Создать виртуальное окружение:

```bash
python3 -m venv .venv
```

Активировать виртуальное окружение (macOS/Linux):

```bash
source .venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## 4. Обучение модели

Для подготовки данных и обучения модели выполнить команду:

```bash
python train.py
```

После выполнения скрипта обученная модель и метаданные сохраняются в каталоге `artifacts/`.

## 5. Запуск автоматических тестов

Для проверки работоспособности проекта выполнить:

```bash
python -m pytest -q
```

## 6. Запуск сервиса

Запустить REST API:

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8077
```

После запуска документация API доступна по адресу:

http://localhost:8077/docs

В сервисе реализованы следующие endpoints:

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/health` | Проверка работоспособности сервиса |
| GET | `/model-info` | Информация о модели |
| POST | `/predict` | Предсказание качества вина |

## 7. Запуск через Docker

Собрать Docker-образ:

```bash
docker build -t wine-quality-service:1.0.0 .
```

Запустить контейнер:

```bash
docker run --rm -p 8077:8077 wine-quality-service:1.0.0
```

После запуска сервис доступен по адресу:

http://localhost:8077/docs

Проверить работу сервиса:

```bash
curl http://localhost:8077/health
```

Посмотреть запущенные контейнеры:

```bash
docker ps
```

Для остановки контейнера нажать `Ctrl + C` в терминале.
